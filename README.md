# Stratum

A three-layer exploration map for deep technical study. You clear shrines (a small build plus a write-up committed here), and the map is rendered from the repo: fog lifts, lightroots glow and paths appear as a side effect of doing the work.

```sh
npm install
npm run stratum -- setup    # once per machine: detect hardware tags
npm run dev                 # http://127.0.0.1:5173 (keys 1/2/3 switch layers)
npm test
```

- `DESIGN.md` is the spec.
- `docs/status.md` covers progress and next steps.
- `docs/decisions.md` explains the choices made along the way.
- `CLAUDE.md` is the guide for coding agents.
