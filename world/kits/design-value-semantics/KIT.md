# Kit: the "before" API for Regular types

`order_book.hpp` is a small, header-only limit order book written in a reference-heavy style; `main.cpp` shows a client using it. Redesign it around values.

Build and run: `cmake -S . -B build && cmake --build build && ./build/order_book_demo`

This is the starting point; your work goes alongside it. Keep this version as the "before" and put your redesign next to it.
